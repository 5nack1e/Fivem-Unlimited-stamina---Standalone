# Arcane Unlimited Stamina

A lightweight standalone FiveM resource that keeps player stamina full.

## Features
- Unlimited sprint stamina for all players.
- Standalone resource with no framework dependency.
- Minimal and performance-friendly client script.

## Installation
1. Place `arcane_unlimited_stamina` in your server resources folder.
2. Add this line to your `server.cfg`:

```cfg
ensure arcane_unlimited_stamina
```

## Configuration
No configuration is required.

## Compatibility
- FiveM (GTA V)
- OneSync supported

## Support
If you run into issues, open an issue in this repository with your error log and server artifact version.
